Static demo. This copy runs without the Python server, so it can only show the built-in sample. Scanning your own photo, exporting STL, and MIDI/WAV downloads need the studio running locally: clone the repo and run python webapp/server.py.

Loop

Click a cell to add or remove a note. Rows are the 16 pitches the comb can play (Ab major, Eb4 to Bb6); pitches with two tines are marked ×2 and can repeat faster. Grey cells would sit too close to the previous pin on that track.

Disc map

Angle 0 is at 3 o'clock (orange = tone arm); the disc turns clockwise, so the loop runs anticlockwise. Inner tracks are low notes.
